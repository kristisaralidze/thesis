# EASEPM - Enterprise Architecture and Systems Engineering Project Management

A comprehensive application for managing enterprise architecture and systems engineering projects. This repository contains both the frontend and backend components of the EASEPM system.

## Project Structure

- **easepm-frontend/**: React-based frontend application
- **easepm-backend/**: Python Flask-based backend API

## Frontend Technologies

- React
- Chart.js
- D3.js
- React Flow
- Framer Motion
- Recharts

## Backend Technologies

- Python
- Flask
- Firebase Integration

## Getting Started

### Frontend Setup

```bash
cd easepm-frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd easepm-backend
pip install -r requirements.txt
python app.py
```

## Features

- Enterprise architecture visualization
- Project management tools
- Systems engineering workflow integration
- Data analytics and reporting
